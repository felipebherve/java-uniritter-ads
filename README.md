## Where I was when I made this

In 2026 I started the **Análise e Desenvolvimento de Sistemas (ADS)** degree at UniRitter (distance learning). This repository has my notes and code for the first course, **Algorithms and Programming**, from the first weeks (late August to mid-September 2026).

Before this I had learned JavaScript on my own and finished a Python/Django backend course, so I already knew how to make things work. What I was missing was the formal foundation, and this course is where I'm getting it, this time in **Java**.

## What I learned so far

- **Unit 2 — logic and Java basics:** how a program goes from source to execution (`.java` → `javac` → bytecode → JVM), the difference between JDK, JRE and JVM, IDEs, conditionals, loops and modularization.
- **Unit 3 — data structures:** arrays, matrices and collections, and how to manipulate data in them.
- **Unit 4 — implementing algorithms:** code quality, control structures, functions and modularization, and testing algorithms.
- **Unit 5 — object-oriented programming (in progress):** classes, objects, encapsulation, relationships between classes and reuse, with modeling examples such as an order system (customer, order, order item, composition).

## Run the examples

You need a JDK installed (`java -version` and `javac -version` should both work).

```bash
cd exemplos
javac HelloWorld.java
java HelloWorld
```
