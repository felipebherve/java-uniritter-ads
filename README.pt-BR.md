## Em que momento eu fiz isto

Em 2026 comecei o curso de **Análise e Desenvolvimento de Sistemas (ADS)** na UniRitter (EAD). Este repositório tem minhas anotações e códigos da primeira disciplina, **Algoritmos e Programação**, das primeiras semanas (do fim de agosto a meados de setembro de 2026).

Antes disso eu tinha aprendido JavaScript sozinho e concluído um curso de backend com Python/Django, então já sabia fazer as coisas funcionarem. O que me faltava era a base formal, e é isso que estou construindo aqui, desta vez em **Java**.

## O que aprendi até agora

- **Unidade 2 — lógica e básico de Java:** como um programa vai do código-fonte à execução (`.java` → `javac` → bytecode → JVM), a diferença entre JDK, JRE e JVM, IDEs, condicionais, laços de repetição e modularização.
- **Unidade 3 — estruturas de dados:** arrays, matrizes e coleções, e como manipular dados nelas.
- **Unidade 4 — implementação de algoritmos:** qualidade de código, estruturas de controle, funções e modularização, e testes de algoritmos.
- **Unidade 5 — orientação a objetos (em andamento):** classes, objetos, encapsulamento, relacionamentos entre classes e reutilização, com exemplos de modelagem como um sistema de pedidos (cliente, pedido, item de pedido, composição).

## Situação

Em andamento. As anotações têm data para eu enxergar meu progresso semana a semana. Vou acrescentar os exercícios em Java que escrever ao longo do curso.

## Rodar os exemplos

É preciso ter um JDK instalado (`java -version` e `javac -version` devem funcionar).

```bash
cd exemplos
javac HelloWorld.java
java HelloWorld
```
