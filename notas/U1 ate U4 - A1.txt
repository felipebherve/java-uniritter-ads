Estruturas homogêneas~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Uma estrutura homogênea armazena elementos de um mesmo tipo. Um array de números inteiros armazena apenas valores compatíveis com int:
int[] quantidades = {4, 2, 7, 1};
Uma lista de nomes armazena objetos do tipo String:
ArrayList<String> nomes = new ArrayList<>();
A homogeneidade facilita a execução da mesma operação sobre todos os elementos. Por exemplo:
int soma = 0;
for (int quantidade : quantidades) {
    soma += quantidade;
}
Como todos os valores são inteiros, o programa pode somá-los sem precisar descobrir o tipo de cada posição.
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

Estruturas heterogêneas~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
Uma estrutura heterogênea reúne informações de tipos diferentes que descrevem uma mesma entidade.
Um pedido pode conter:
Um número inteiro para a mesa;
Um texto para o produto;
Um número decimal para o preço;
Um valor lógico para indicar pagamento.
Em Java, esse agrupamento costuma ser representado por uma classe:
public class Pedido {
    int numeroMesa;
    String produto;
    double preco;
    boolean pago;
}
A classe Pedido não representa apenas um valor. Ela reúne diferentes atributos relacionados a um mesmo conceito.

#Conceito de array: Um array é uma estrutura que armazena uma quantidade fixa de elementos de um mesmo tipo.

“An array is a container object that holds a fixed number of values of a single type.”
Isso significa que um array funciona como um contêiner com posições previamente definidas e elementos compatíveis com um único tipo. A especificação da linguagem também estabelece que arrays são objetos criados dinamicamente.
Possui um tipo de elemento; Possui um comprimento fixo; Utiliza índices numéricos; Começa no índice zero; Permite acesso direto a uma posição; Pode armazenar valores primitivos ou referências; Pode possuir uma ou várias dimensões.

The Collections Framework is the most widely used API of the JDK
The first thing you need to know is that, from a technical point of view, the Collections Framework is a set of interfaces that models different ways of storing data in different types of containers. Then the Framework provides at least one implementation for each interface. Knowing these implementations is as important as the interfaces, and choosing the right one depends on what you need to do with it.

There is no direct relationship between the interfaces of the Collection hierarchy and the Map hierarchy.

ARRAY vs ARRAYLIST (JAVA)
Conceito Geral:
	• Recomendação: Usar ArrayList para percorrer ou acessar elementos por índice.
	• A escolha depende do padrão de uso do programa.
Comparativo Direto:
	• Tamanho:
		- Array: Fixo
		- ArrayList: Variável (dinâmico)
	• Tipos Primitivos:
		- Array: Aceita diretamente (int, double, char...)
		- ArrayList: Requer Wrapper Classes (Integer, Double, Character...)
	• Acesso por Índice:
		- Ambos suportam (Sim)
	• Inserção e Remoção Prontas:
		- Array: Não
		- ArrayList: Sim (métodos add e remove)

ESTRUTURAS DE DADOS NA PRÁTICA (SISTEMA DE LANCHONETE)
1. Montar o cardápio
	• Estrutura: Map (HashMap)
	• Conceito: Mapeia uma chave (código) para um valor (nome do produto).
	• Código Java:
		Map<Integer, String> cardapio = new HashMap<>();
		cardapio.put(101, "Café");
		cardapio.put(205, "Suco");
		cardapio.put(310, "Bolo");
		cardapio.put(420, "Sanduíche");
2. Localizar o produto
	• Estrutura: Map (HashMap)
	• Conceito: Busca rápida por chave utilizando o método get().
	• Código Java:
		int codigoInformado = 205;
		String produto = cardapio.get(codigoInformado);

		if (produto == null) {
		    System.out.println("Código inválido.");
		} else {
		    System.out.println("Produto localizado: " + produto);
		}
3. Registrar o pedido
	• Estruturas: 
		- List (ArrayList): Guarda o histórico sequencial de pedidos registrados.
		- Queue (ArrayDeque): Fila de preparo na cozinha (FIFO - Primeiro que entra, primeiro que sai).
	• Código Java:
		List<String> pedidosRegistrados = new ArrayList<>();
		Queue<String> filaPreparacao = new ArrayDeque<>();

		pedidosRegistrados.add(produto);
		filaPreparacao.offer(produto);
4. Controlar código promocional
	• Estrutura: Set (HashSet)
	• Conceito: Conjunto de elementos únicos (não permite duplicatas). O método add() retorna false se o item já existir.
	• Código Java:
		Set<String> codigosUtilizados = new HashSet<>();
		String codigoPromocional = "PROMO10";

		boolean aceito = codigosUtilizados.add(codigoPromocional);

		if (!aceito) {
		    System.out.println("Código já utilizado.");
		}
5. Contar a venda
	• Estrutura: Map (HashMap)
	• Conceito: Associa o nome do produto à quantidade vendida. O getOrDefault() recupera o valor atual ou 0 caso seja o primeiro item.
	• Código Java:
		Map<String, Integer> quantidadeVendida = new HashMap<>();

		int quantidadeAtual = quantidadeVendida.getOrDefault(produto, 0);
		quantidadeVendida.put(produto, quantidadeAtual + 1);
6. Concluir o próximo pedido
	• Estrutura: Queue (ArrayDeque)
	• Conceito: O método poll() remove e retorna o primeiro elemento da fila.
	• Código Java:
		String pedidoConcluido = filaPreparacao.poll();

		if (pedidoConcluido != null) {
		    System.out.println("Pedido concluído: " + pedidoConcluido);
		}

Preparar os dados
Executar o método
Comparar o resultado
Essa organização também é conhecida como:

Arrange
Act
Assert
No exemplo:

preparar: criar o array;
executar: chamar calcularTotal;
verificar: comparar o resultado com 21.

Conclusão
Para sintetizar o que vimos nesse tópico, aprendemos que um processo consistente de implementação envolve:

Compreender
Planejar
Implementar
Executar
Testar
Comparar
Depurar
Corrigir
Testar novamente
